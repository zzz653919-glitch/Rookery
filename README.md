# Rookery — an offline chess learning website

Rookery is a standalone, front-end-only chess academy. It has **no backend, no accounts, no multiplayer and no admin panel**.
Everything — the rules engine, the computer opponent, the lessons, the puzzles, the font, the icons and the pieces — is bundled
and runs in your browser, with or without an internet connection.

It is a completely separate project: it does not read, import or touch any other project on this machine.

## Launch

```bash
cd rookery
npm start          # → http://127.0.0.1:5173
```

No `npm install` is needed (zero dependencies; Node 22.13 or newer). `npm start` runs `server/index.mjs`: it serves the site and
the optional **admin panel** at `/admin/` (see [ADMIN.md](ADMIN.md)). Only need the plain static site? `npm run start:static`
(`scripts/serve.mjs`) or any static server, e.g. `python3 -m http.server 5173` — the player site works without the backend.

### Why not just double-click `index.html`?

Browsers refuse ES modules, Web Workers (the engine runs in one) and service workers (offline caching) on `file://` URLs.
Opening the file directly shows a short explanation with the launch command. Once served from `http://127.0.0.1` the app
works fully offline; after the first load it is cached by a service worker and can even be reloaded with the network off.
It can also be installed as an app (PWA) from the browser menu.

## What is inside

| Area | What you get |
| --- | --- |
| **First visit** | "What is your chess level?" — take the placement test or choose Beginner / Elementary / Intermediate / Advanced / Expert yourself. |
| **Placement test** | 23 questions in 4 difficulty tiers (piece movement, check/checkmate, hanging pieces, forks/pins/skewers, opening principles, mate in 1–2, simple endgames, discovered attacks, calculation, pawn structure). Mixes multiple choice and interactive board tasks. Level = number of consecutive tiers mastered (≥ 60 %, with a bridge rule for 40–60 % when the next tier is ≥ 80 %). Shows strengths, weaknesses and a recommended first lesson, is clearly labelled an **estimate**, ends early when the questions become too hard, and can be retaken from Settings. |
| **Learn** | 29 lessons: Beginner 6, Elementary 6, Intermediate 6, Advanced 6, Expert 5. Each has explanations, an interactive board, graded tasks with hints (three levels of help), immediate feedback that explains wrong moves, a short quiz and a completion mark. A lesson is only completed when **all exercises are solved and the quiz is passed (≥ 60 %)**. The path puts lessons covering your weak skills first. |
| **Puzzles** | 6 themes (mate in 1, mate in 2, forks, pins, skewers, discovered attacks) × 5 difficulty levels, hints, explanations with the solution line, a **daily puzzle** (same for everyone at the same level on the same date), streaks and personal records. |
| **Play** | Play against the built-in engine: 8 difficulty levels, choose colour, optional clocks, resign / restart / draw offer, practice mode with undo and hints, result screen, PGN copy. |
| **Board** | Full rules (castling, en passant, promotion, check, checkmate, stalemate, insufficient material, threefold repetition, fifty-move rule), click *and* drag, touch support, legal-move dots, last-move and check highlights, move history, captured pieces, flip, optional coordinates, 5 board themes and 4 piece sets. Illegal moves are rejected by the rules engine itself — legality is never only visual. |
| **Progress** | Level, lessons completed, puzzle accuracy, recent results, strengths and weaknesses, streaks, achievements, recommended next lesson. |
| **Settings** | Light/dark theme, board and piece themes, coordinates, sound, animations, retake placement test, engine and offline status, backup export/import, reset. |

Progress is stored on **this device only** (IndexedDB, with a localStorage fallback). It does not sync between devices, and
clearing browser data erases it. The Progress and Settings pages say so, and Settings can export/import a JSON backup.

## Honest notes about what this is (and is not)

* **There is no Stockfish and no chess.js.** This build environment could not reach the npm registry or GitHub, so both the
  *rules engine* (`js/chess/rules.js`, 0x88 board, verified with perft) and the *computer opponent* (`js/chess/engine.js`) were
  written from scratch and are bundled. The opponent is a real search engine — iterative-deepening alpha-beta with
  transposition table, null-move pruning, late-move reductions, quiescence search and a tapered evaluation — not random moves.
  Levels 1–5 deliberately weaken it by choosing among near-best moves (they can blunder, like a human learner); levels 6–8
  search deeper with a time limit. Levels are *relative*; they are **not** calibrated Elo ratings. It is much weaker than Stockfish.
* The placement result is an estimate from 23 questions, not a rating.
* Puzzles are generated by self-play and random few-piece motif generation (`scripts/gen-*.mjs`), and each one is accepted only
  if search proves a **unique** best first move. Mate puzzles are additionally re-checked by an exhaustive solver in the tests.
  The bundled set has 288 puzzles; coverage is uneven (e.g. mate-in-1 exists only at level 1, mate-in-2 only at levels 2–3, pins mostly level 3; the hub then says so and Train falls back to other levels). Re-run `npm run puzzles` after generating more with `scripts/gen-motifs.mjs`. They are original but often "clean laboratory" positions rather than positions from real games. There are no Lichess/Chess.com puzzles.
* The only bundled font is Inter (SIL OFL, license included). Piece graphics are original SVGs.
* Lesson depth varies: the Beginner–Intermediate lessons have several graded board exercises each; some Advanced and Expert
  lessons (strategy topics such as prophylaxis or converting an advantage) are mainly explanations plus one multiple-choice
  task and a quiz, because strategy cannot be verified by an exact-answer board puzzle. Rook-ending theory (Lucena, Philidor)
  is explained but not drilled with a verified board exercise.
* Sounds are synthesised with WebAudio (no audio files).

```
tests/                                                   unit/content tests (node --test) and browser e2e tests (tests/e2e)
```

## Tests

```bash
npm test                      # rules (perft), engine, lesson/placement/puzzle content validation, placement scoring, learning path
npm start                     # in another terminal, then:
node tests/e2e/run.mjs        # real-browser tests (needs Playwright + Chromium: `npm i -D playwright`)
```

What the tests check:

* **Rules**: perft node counts on standard positions, castling, en passant, promotion, checkmate/stalemate/draw detection, SAN, PGN round-trips.
* **Engine**: finds mates in 1–2, wins hanging material, escapes mate threats, converts K+Q and K+R vs K, returns legal moves at every difficulty over whole games. (`npm run selfplay` is a separate, manual level-vs-level strength check; it is not part of `npm test`.)
* **Content**: every FEN is a legal position; every accepted move is legal; "mate" tasks accept *exactly* the set of mating moves;
  mate-in-two tasks accept exactly the forcing first moves and the scripted replies are legal; "best move" tasks agree with the engine;
  threat questions are verified by search; the SAN opening/game lines are legal (and the famous games end in checkmate);
  placement items follow the same rules; every lesson has a task and a quiz; puzzle solutions are legal and mates really mate.
* **Placement scoring**: all-wrong → Beginner, each mastered tier raises the level, 60 % threshold, bridge rule, consecutive-tier rule.
* **E2E (browser)**: first-visit flow, manual level choice, persistence after reload, all six nav links, the placement test taken
  three ways, **every one of the 29 lessons played through with real clicks** (including hints, gated Continue button, quiz),
  failed quiz does not complete a lesson, personalised learning path per level, puzzles (hint, wrong move, solution, streak, daily),
  playing the computer with the network switched off, illegal-move rejection, settings persistence, backup export, reset,
  desktop/tablet/mobile layouts with no horizontal overflow, service-worker offline reload, and zero console errors.
